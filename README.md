# Pediatric Medevac — Analysis Project

Retrospective analysis of pediatric medevac operations across the Maniilaq Association
service area (Northwest Arctic Borough, Alaska), 2020–2024.

---

## Architecture

```
medevac_pipeline_project/   ← sibling repo: PHI data engineering (produces data/final/pediatric/)
pediatric_data/             ← this repo: analysis and manuscripts
  analysis/
    python/
      medevac_data_prep.py  ← Step 1: loads source data, exports analysis-ready CSVs
    R/
      utils.R               ← shared R helpers and data loaders
      paper1_tables.R       ← gtsummary/gt table builders for Paper 1
    medevac_summaries.py    ← Step 2: figure generation (PNG outputs)
    medevac_map_fig1.py     ← geographic map figure
  manuscripts/
    paper1/paper1_results.qmd   ← Paper 1 results (knitr/R engine)
    paper2/paper2.qmd
    paper3/paper3.qmd
  outputs/
    data/       ← Python-generated analysis-ready CSVs (gitignored, regenerated by pipeline)
    figures/    ← Python-generated PNGs (gitignored, regenerated by pipeline)
    tables/     ← legacy Python table CSVs (being phased out)
  data/         ← gitignored: PHI data or de-identified synthetic extract
```

**Language responsibilities:**
- **Python** — data engineering: loading, filtering, deriving variables, generating figures
- **R** — all statistical analysis and table formatting (`gtsummary`, `gt`)
- **Quarto** — assembles pre-computed outputs into manuscripts (knitr/R engine)

## Setup (new machine)

### Prerequisites

| Tool | Version | Install |
|------|---------|---------|
| Python | 3.12 | [python.org](https://www.python.org) or pyenv |
| R | ≥ 4.4 | [r-project.org](https://www.r-project.org) |
| Quarto | ≥ 1.5 | [quarto.org](https://quarto.org) |

### 1. Clone and enter the repo

```bash
git clone <repo-url>
cd pediatric_data
```

### 2. Install Python dependencies

```bash
pip install -r requirements.txt
```

### 3. Install R dependencies (via renv)

```bash
Rscript -e "renv::restore()"
```

This reads `renv.lock` and installs the exact package versions into `renv/library/`.
Only needed once per machine, and again after `renv.lock` changes.

### 4. Place data

**PHI machine:** The pipeline reads from the sibling `medevac_pipeline_project` repo
(`../medevac_pipeline_project/data/final/pediatric/`). No extra steps needed if that
repo is cloned alongside this one.

**Local / de-identified:** Copy the synthetic extract into `data/` and use the
`-synthetic` flag (see below).

## Running the pipeline

```bash
# PHI machine (real data):
python scripts/run_full_pipeline.py

# Local / de-identified machine:
python scripts/run_full_pipeline.py -synthetic

# Skip Quarto (data + figures only):
python scripts/run_full_pipeline.py -synthetic --skip-quarto

# Skip data/figures (Quarto re-render only):
python scripts/run_full_pipeline.py --skip-analysis
```

**Pipeline steps:**
1. `analysis/python/medevac_data_prep.py` → `outputs/data/*.csv`
2. `analysis/medevac_summaries.py` → `outputs/figures/*.png`
3. `quarto render manuscripts/paper1/paper1_results.qmd` (R builds tables inline)

## Reproducibility notes

| Layer | Tool | File |
|-------|------|------|
| Python packages | pip | `requirements.txt` (pinned versions) |
| Python version | pyenv / .python-version | `.python-version` |
| R packages | renv | `renv.lock` (pinned versions) |
| R version | documented | R ≥ 4.4.2 (see `renv.lock`) |
| Quarto version | documented | ≥ 1.5 |

**Never commit:**
- `data/` — PHI patient data
- `outputs/data/` — generated artifacts (reproducible from pipeline)
- `outputs/figures/` — generated artifacts
- `renv/library/` — binary packages (machine-specific)

**Always commit:**
- `renv.lock` — R package versions
- `renv/activate.R`, `renv/settings.json`, `.Rprofile` — renv bootstrap
- `requirements.txt` — Python package versions
- `.python-version` — Python version pin
