# Pediatric Medevac — Analysis Project
<!-- sync check: 2026-06-30 -->

Retrospective analysis of pediatric medevac operations across the Maniilaq Association
service area (Northwest Arctic Borough, Alaska), 2020–2024.

---

## Architecture

```
medevac_pipeline_project/   ← sibling repo: PHI data engineering (produces data/final/pediatric/)
pediatric_data/             ← this repo: analysis and manuscripts
  analysis/
    python/
      medevac_data_prep.py      ← Step 1: loads source data, exports analysis-ready CSVs
      export_analysis_data.py   ← Step 2: exports paper1_route_comparison.csv for R
      medevac_summaries.py      ← Step 4: figure generation (PNG outputs)
      medevac_map_fig1.py       ← geographic map figure
    R/
      utils.R               ← shared R helpers and data loaders
      paper1_tables.R       ← gtsummary/gt table builders for Paper 1
      paper1_figures.R      ← ggplot2/sf figures for Paper 1
      paper1_stats.R        ← Step 3: inferential tests → outputs/stats/
  manuscripts/
    paper1/paper1_results.qmd        ← Paper 1 results (knitr/R engine)
    paper1/external_manuscript.qmd   ← anonymized (Village A–K, no map) version for external collaborators
    paper2/paper2.qmd
    paper3/paper3.qmd
  outputs/
    data/             ← Python-generated analysis-ready CSVs (gitignored, regenerated by pipeline)
    stats/            ← R-generated p-values and model results (committed — reproducibility audit)
    figures/          ← Python-generated PNGs (gitignored, regenerated by pipeline)
    figures_external/ ← anonymized-village copies of 3 figures, for external_manuscript.qmd (gitignored)
    tables/     ← legacy Python table CSVs (being phased out)
  docs/
    external_village_codebook.csv/.md  ← real village name <-> "Village A".."Village K" key (gitignored — never commit)
    village_name_codebook.csv/.md      ← decodes synthetic Village_* placeholders back to real names (committed)
  data/         ← gitignored: PHI data or de-identified synthetic extract
  Makefile      ← orchestration: make all / make all SYNTHETIC=1
```

**Language responsibilities:**
- **Python** — data engineering: loading, filtering, deriving variables, generating figures
- **R** — all statistical analysis and table formatting (`gtsummary`, `gt`)
- **Quarto** — assembles pre-computed outputs into manuscripts (knitr/R engine)

## Setup (new machine)

### Prerequisites

| Tool | Version | Install |
|------|---------|---------|
| Python | 3.12 | [python.org](https://www.python.org) or pyenv |
| R | ≥ 4.4 | [r-project.org](https://www.r-project.org) |
| Quarto | ≥ 1.5 | [quarto.org](https://quarto.org) |

### 1. Clone and enter the repo

```bash
git clone <repo-url>
cd pediatric_data
```

### 2. Install Python dependencies

```bash
pip install -r requirements.txt
```

### 3. Install R dependencies (via renv)

```bash
Rscript -e "renv::restore()"
```

This reads `renv.lock` and installs the exact package versions into `renv/library/`.
Only needed once per machine, and again after `renv.lock` changes.

### 4. Place data

**PHI machine:** The pipeline reads from the sibling `medevac_pipeline_project` repo
(`../medevac_pipeline_project/data/final/pediatric/`). No extra steps needed if that
repo is cloned alongside this one.

**Local / de-identified:** Copy the synthetic extract into `data/` and use the
`-synthetic` flag (see below).

## Running the pipeline

```bash
# PHI machine (real data):
python scripts/run_full_pipeline.py

# Local / de-identified machine:
python scripts/run_full_pipeline.py -synthetic

# Skip Quarto (data + figures only):
python scripts/run_full_pipeline.py -synthetic --skip-quarto

# Skip data/figures (Quarto re-render only):
python scripts/run_full_pipeline.py --skip-analysis
```

**Pipeline steps:**
1. `analysis/python/medevac_data_prep.py` → `outputs/data/*.csv`
2. `analysis/python/export_analysis_data.py` → `outputs/data/paper1_route_comparison.csv`
3. `analysis/R/paper1_stats.R` → `outputs/stats/paper1_table3_pvalues.csv`
4. `analysis/python/medevac_summaries.py` → `outputs/figures/*.png` + `outputs/figures_external/*.png`
5. `quarto render manuscripts/paper1/paper1_results.qmd` (R builds tables via gtsummary)
6. `quarto render manuscripts/paper1/external_manuscript.qmd --to html` (anonymized villages; skipped with a warning if step 7 below hasn't been done locally)

Run all steps in order via `make all` (or `make all SYNTHETIC=1` for de-identified data).

### External / anonymized manuscript

`manuscripts/paper1/external_manuscript.qmd` renders the same results with
real village/community names replaced by anonymous labels (`Village A`
through `Village K`, consistent across every table and figure) and the
geographic service-district map omitted entirely. It's meant for sharing
with external collaborators who shouldn't be able to identify a specific
community.

This requires a local-only codebook that is **never committed to git**
(the letter↔real-name key is exactly what lets someone reverse the
anonymization):

```bash
docs/external_village_codebook.csv   # original_village,coded_village
docs/external_village_codebook.md    # provenance/notes
```

See `docs/external_village_codebook.md` for the mapping and how to recreate
it on a new machine (it reuses the same `Village A`–`K` assignment already
used by `medevac_pipeline_project`'s own de-identification step). If this
file is missing, both the R and Python anonymize helpers raise a clear
error rather than silently falling back to real names, and
`run_full_pipeline.py` / `make render` will print a warning and skip the
external manuscript while still producing the internal one.

## Reproducibility notes

| Layer | Tool | File |
|-------|------|------|
| Python packages | pip | `requirements.txt` (pinned versions) |
| Python version | pyenv / .python-version | `.python-version` |
| R packages | renv | `renv.lock` (pinned versions) |
| R version | documented | R ≥ 4.4.2 (see `renv.lock`) |
| Quarto version | documented | ≥ 1.5 |

**Never commit:**
- `data/` — PHI patient data
- `outputs/data/` — generated artifacts (reproducible from pipeline)
- `outputs/figures/*.png`, `outputs/figures_external/*.png` — generated artifacts (see `outputs/figures/README.md`)
- `docs/external_village_codebook.csv`/`.md` — re-identification key for the external manuscript
- `renv/library/` — binary packages (machine-specific)

### Syncing code on PHI (without PNG pull conflicts)

Figure PNGs used to be tracked in git; they are **not** anymore. If `git pull` stalls or conflicts on `outputs/figures/`, use:

```bash
bash scripts/git_pull.sh
python3 scripts/run_full_pipeline.py
```

Or manually: `git fetch origin && git restore outputs/figures && git merge --ff-only origin/main`

**Always commit:**
- `renv.lock` — R package versions
- `renv/activate.R`, `renv/settings.json`, `.Rprofile` — renv bootstrap
- `requirements.txt` — Python package versions
- `.python-version` — Python version pin
